📘 Manual da Linguagem Vortex Script v7.0

📘 Vortex Script v7.0 Language Guide

A linguagem do Vortex OS é focada no desenvolvimento de apps, canvas 2D, som e integração com banco global.

Comandos Principais:

  • criar variavel = valor; -> Declaração de variáveis.
  • exibir("mensagem"); -> Imprime dados no console do sistema.
  • limpar_tela(); -> Limpa o Canvas da aplicação.
  • desenhar_retangulo(x, y, w, h, "cor"); -> Desenha um retângulo.
  • desenhar_circulo(x, y, raio, "cor"); -> Desenha um círculo.
  • desenhar_texto("Texto", x, y, "cor", tamanho); -> Escreve texto no Canvas.
  • tocar_som(frequencia, "tipo", duracao); -> Sintetizador de áudio nativo.
  • se_tecla("ArrowUp") -> Verifica se a tecla está pressionada.
  • se_mouse_clicado() / mouse_x() / mouse_y() -> Suporte a mouse.
  • vortex_pix("usuario", valor); -> Transfere dinamicamente dinheiro no banco do OS!
